# Simplify WordPress Article Import Wizard

Initial release of a WordPress plugin scaffold and first functional workflow slice.

Version: 0.0.1
Author: GitHub Copilot and Jens

## Included in this release

- Guided admin import screen for editor and author roles
- Membership-number based public author attribution
- Internal operator tracking in post metadata
- Draft post creation flow
- DOCX parsing foundation
- Inline image placeholder mapping foundation
- Link validation and notification service foundations
- Plugin settings page for core defaults

## Notes

- Public author identity is separated from the operator identity.
- Imported posts are created as drafts.
