Article Import for InDesign

Version 1.0.0 · Script ArtikelImport.jsx · for Adobe InDesign

The script sets an article from a Word file (.docx) into the open InDesign document. The Word file contains short markers in square brackets, for example [TITLE: …] for the title or [Bild 1: …] for a picture caption. The script reads these markers and puts each part in the right place.

  • Template with placeholders: the article goes into the frames marked [TITEL], [TEXT], [BILD 1] and so on. The pictures are placed as well.
  • Any other document: select a text frame (or click into a text), and the whole article is set there with the document's own paragraph styles.

The marker and placeholder names are German (Titel = title, Bild = picture, Bildunterschrift = caption, Vorspann = intro, Reisezeit = travel period, Autor = author). Use them exactly as shown.

1. Installation

  1. In InDesign, open Window > Utilities > Scripts.
  2. Right-click User and choose Reveal in Explorer (Windows) or Reveal in Finder (Mac).
  3. Copy ArtikelImport.jsx into the Scripts Panel folder that opens.
  4. The script now appears under User in the Scripts panel.

To update, replace the file with the new one.

2. Importing an Article

  1. Open the template, or the document the article should go into.
    Without placeholders: select the text frame for the article, or click into a text where it should start.
  2. Double-click ArtikelImport.jsx in the Scripts panel.
  3. Choose the Word file (.docx).
  4. Check the dialog:
    • Author and Travel period come from the Word file and can be changed here.
    • Pictures shows which picture file was found for each placeholder. Folder... chooses another picture folder.
    • Please check lists problems, such as a missing picture or a marker that was not recognized.
    • Styles... chooses the paragraph and character styles (see section 7).
  5. Click Import. Enter does not start the import; only the button does.

A message then lists what was done and what needs checking, for example overset text. Edit > Undo reverts the whole import in one step.

3. The Word File

Each marker stands in its own paragraph (picture markers may also stand inside a sentence). Upper and lower case do not matter.

Marker in WordResult in InDesign
[TITLE: Headline]Title → [TITEL]. Without this marker, a paragraph in Word's Title or Heading 1 style becomes the title, otherwise the first paragraph (which then is not repeated in the body text).
[SUBTITLE: Sub-headline]Subtitle → [UNTERTITEL]
[AUTHOR_NAME: First Last]Author name → [AUTOR]; can be changed in the dialog
[REISEZEIT: May to August 2024]Travel period → [REISEZEIT]; can be changed in the dialog
[HEADER Section headline]
[HEADER 3 …], [HEADER 4 …]		Headings in the body text (three levels)
[Bild 1: Caption]
[Bild 2], [Image 3: …]		The caption goes into [BILDUNTERSCHRIFT 1], the picture file Bild 1 into [BILD 1]. The marker itself is removed from the text.
[BIO: Short text about the author]Author bio → [BIO]. It may span several paragraphs; end it with ].
[AUTHOR_MEMBERSHIP: …], [WRITING_DATE: …], [RESTRICT]Only used on the website; removed in print.
  • The first paragraph of the article becomes the Vorspann (intro).
  • Bold, italic, links and bulleted or numbered lists (also nested) are kept. Links become InDesign hyperlinks, so they work in an interactive PDF.
  • Underline, colours, fonts, tables and pictures inside the Word file are not taken over.
  • Always save as .docx, not .doc.

[SUBTITLE: ]
[AUTHOR_NAME: ]
[REISEZEIT: ]

Second paragraph with a picture marker [Bild 1: Caption].

[HEADER Section headline]
Another paragraph.

[Bild 2: Caption]

[BIO: ]

4. Pictures

The script looks for picture files in the folder of the Word file, and in its subfolders Links, Bilder, Images and Fotos. The file name decides where a picture goes. Upper and lower case, spaces, _ and - do not matter.

PlaceholderFile names, e.g.
[AUFMACHERBILD] (headline picture)Aufmacherbild.jpg, Titelbild.jpg
[BILD n]Bild 1.jpg, Bild_1.jpg, Bild-01.tif, Image 1.png
[AUTORENBILD] (author picture)Autorenbild.jpg, BioPic.jpg

JPEG, PNG, TIFF, PSD, PDF, EPS and AI files are placed, linked to the original file. Do not move the pictures after the import, or relink them in the Links panel.

5. Template with Placeholders

A template gets text frames with these placeholders. Design, styles, master pages and so on are entirely up to you.

PlaceholderWhereReplaced with
[TITEL]Title frameArticle title
[UNTERTITEL]Subtitle frameSubtitle
[AUTOR]Anywhere in a line, e.g. Text und Fotos: [AUTOR]Author name from the dialog
[REISEZEIT]Anywhere in a line, e.g. Reisezeit: [REISEZEIT]Travel period from the dialog
[VORSPANN]Own paragraph in the intro frameFirst paragraph of the article
[TEXT]Every body text frameThe body text. All [TEXT] frames are threaded into one story in reading order: spread by spread, left to right, top to bottom. Other text in these frames is replaced.
[BIO]Own paragraph in the author boxAuthor bio; the rest of the box stays
[BILDUNTERSCHRIFT n]Caption frameCaption from [Bild n: …]
[BILD n], [AUFMACHERBILD], [AUTORENBILD]Small text frame on top of an empty graphic frameThe picture goes into the graphic frame below; the small text frame is deleted. Without Frame Fitting Options, the picture fills the frame proportionally, centred.
  • A line whose placeholder gets no value is removed, for example Reisezeit: [REISEZEIT] without a travel period.
  • Picture frames without a picture stay empty; text that does not fit stays overset. Adjust the page count and breaks by hand afterwards.
  • Placeholders keep their paragraph style and local formatting. Headings, lists and captions in the body text use the styles chosen under Styles....
  • A template can be saved as .indt; InDesign then opens an untitled copy each time.

6. Document without Placeholders

If the document has no [TEXT] placeholder, the script needs a target: a selected text frame (the article is added at the end of its story), a text cursor, or selected text (which is replaced). The whole article is set there in this order: title, subtitle, author, Vorspann, body text with the picture markers and captions, author name and bio.

Pictures are not placed in this case, because the script cannot know where they go. The lines [Bild 1] and so on show where they belong.

7. Styles

Styles... in the dialog chooses a style of the open document for each part of the article. The choice is saved in the document: a template saved after the choice keeps it. The last choice is also suggested for other documents.

Your styles do not need these names; simply choose your own styles under Styles.... Styles inside style groups are offered too.

In a template with placeholders, title, subtitle, author line, Vorspann, captions and bio always keep the style of their placeholder; the body text takes the style of [TEXT].

When a paragraph's font has no bold or italic style, the text is still marked with it. InDesign then shows it as a missing font, so the emphasis is not lost. The message names the font: install it, or choose a character style for bold and italic under Styles....

8. Messages

Before the import, Please check in the dialog lists problems in the Word file and the picture folder:

  • no title; a marker that appears twice; [BIO: without a closing ]
  • a marker that was not recognized and stays in the text, e.g. [HEADER Warnungen} with the wrong bracket
  • skipped or repeated picture numbers, a picture marker without a picture file, a picture file without a marker (it is placed without a caption), or a picture the template has no frame for
  • style names that the document does not have

After the import, the message adds overset text and missing font styles.

9. Trying It Out

  1. Create a new document and draw a large text frame. Leave the frame selected.
  2. Run the script and choose Beispiel/Beispielartikel.docx.
  3. Click Import in the dialog. The whole article is now in the frame.

With your own template with placeholders, the four example pictures in the Beispiel folder are placed as well.

10. Notes

  • Tested with InDesign 2027 on Windows. Written for InDesign CS6 and newer on Windows and Mac; other versions are untested.
  • The dialogs are in German when InDesign runs in German, otherwise in English.
  • The script reads the Word file with InDesign's own Word import. It does not change the Word file or the pictures and sends no data to the internet.
  • The import is a single undo step. Still, save the document before importing.
